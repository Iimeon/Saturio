XULFADP para Chrome — instalación como favorito

No instala ninguna extensión. Todo el procesamiento se realiza dentro de la pestaña de SharePoint/Stream.

Instalación

  1. Muestra la barra de favoritos con Ctrl + Mayús + B.
  2. Arrastra el botón azul hasta la barra de favoritos:

⬇ XULFADP

Si Chrome no permite arrastrarlo, pulsa este botón, crea un favorito cualquiera, edítalo y pega el contenido copiado en el campo URL.

Uso

  1. Abre la grabación directamente en SharePoint o Microsoft Stream.
  2. Espera hasta que el vídeo pueda reproducirse.
  3. Pulsa el favorito XULFADP.
  4. Usa el panel que aparecerá para descargar vídeo, audio o transcripción.

Dentro de Teams: si no aparece el panel, usa «Abrir en SharePoint» o abre la grabación en una pestaña nueva y vuelve a pulsar el favorito.

Límites: no descarga vídeos con DRM. Las políticas corporativas de Chrome pueden bloquear los favoritos JavaScript. La pestaña debe permanecer abierta mientras se genera el MP4.

Utilízalo únicamente con grabaciones que tengas autorización para reproducir y guardar.
